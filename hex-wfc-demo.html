🔬 Cubic Hexagonal Grid WFC Demo

This demonstrates using a custom grid with the Schrodinger WFC library.

The CubicHexagonalGrid is implemented as an external JavaScript class that follows the Grid interface.

Features:

  • Uses cubic coordinates [x, y, z] where x + y + z = 0
  • Supports 6 hexagonal directions with proper adjacency mapping
  • Works seamlessly with the core WFC library
  • Demonstrates third-party grid extensibility
